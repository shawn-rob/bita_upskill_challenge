# Let The Source Be With You #

## Installing from the source code ##

Previously, the modules installed packages and repositories. Those were already prepackaged binaries. Using source code, you have to build it binary and possibly downloading other tools and dependencies. 
In this module nmap is installed through the source code. At the beginning of the module, the most current version is 7.98. it is located in the /usr/bin/nmap. To install the newest stable version of 7.993, the nmap tarball is downloaded and uncompressed. The new copy of nmap is located in /usr/local/bin/nmap 

---

The thing with installing from the source code instead of the apt install is that it does not get updates when doing **apt update**
